# dlpi_promiscon

`dlpi_promiscon` は、Solaris/Illumos 系システムでネットワークインターフェースを **プロミスキャスモード** に設定するためのユーティリティです。  
プロミスキャスモードを有効にすると、インターフェースは自分宛以外のパケットも含め、同一ネットワーク上のすべてのパケットを受信できるようになります。

## ビルド方法

このプログラムは `libdlpi` を利用するため、開発環境に `libdlpi` が必要です。

```sh
cc -o dlpi_promiscon dlpi_promiscon.c -ldlpi
```

## 使い方

```sh
./dlpi_promiscon <network-interface>
```

例: `net0` をプロミスキャスモードにする場合

```sh
./dlpi_promiscon net0
```

## 利用シナリオ（ネスト仮想化）

仮想スイッチやブリッジの下にさらに仮想 NIC を作成する場合、親インターフェースは通常「自分の MAC アドレス宛」だけを受信します。
そのままでは下流で発行された別の MAC 宛フレームを受信できず、仮想 NIC が正しく通信できません。

このような場合に プロミスキャスモード を有効にすることで、上位インターフェースがすべてのフレームを受け取り、下流の仮想 NIC や VNIC まで届けられるようになります。


## 注意点

- 実行には **root 権限** が必要です。
- Solaris/Illumos 専用であり、Linux/BSD では動作しません。
- プロミスキャスモードはセキュリティリスクがあるため、必要な用途に限定してください。
